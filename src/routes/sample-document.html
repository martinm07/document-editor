Introducing a Light, Visual HTML Editor

How to use (Level 1: HTML)

The editor requires a mouse/trackpad and keyboard to use, and has been designed purely for desktop and laptop screens.

There are some things you should understand about the technologies this editor interacts with before continuing:

  1. HTML stands for HyperText Markup Language. It is the language your browser reads to understand the structure of all content on the World Wide Web. 
  2. A HTML document consists of text content and 'elements'. Any text you see on a web page is text content, and it must be contained inside an element, which itself consists of: 
    1. A 'tag name [1]' describing what the element is, or what kind of content it will contain. 
      For example, an element with tag name 'p' indicates it contains a paragraph. An 'img' element indicates it is an image.
    2. 'Attributes ', which give extra information about the element. 
      For example, a 'src' attribute with the location of an image file informs the browser about what image to load when rendering an 'img' element. Or a 'title' attribute that specifies some text makes that text get displayed when a reader hovers over the element.
    3. Their relationships to other elements. All elements in a HTML document are part of the same 'tree' (like a family tree), existing as children, parents and siblings to each other.
      These relationships generally encode 'who contains what'. Any element contains its children and is contained by its parents.
      For example, an 'em' (emphasis) element contains text to be emphasised, and is contained by a 'p' (paragraph) element.
If you want to learn more about the different HTML tag names and attributes, this document is a good place to start! In the editor sidebar, any piece of HTML or CSS (discussed below) you're curious about should have a  icon next to it. Clicking that will go to a web page explaining it in more detail, giving example use-cases and so on.

This editor allows you to modify all HTML text content and elements (from their tag name, to their attributes, to the relationships between elements).
To do so, you must first select the element you want to modify.

Selecting Elements

When using your mouse to hover your cursor over the contents of this very document you're reading, you should notice a grey outline appear around whatever you hover. You will also notice information being displayed in your left sidebar.
For example, hovering over this text, you will see in the left sidebar that this text is contained by an element with tag name 'p' (displayed as <p>), and a 'title' attribute with the value "This is some text!".

When hovering over an element, you can also choose to hover over one of its parents instead, by pressing Shift while scrolling up, or while pressing the Up Arrow key. Scroll down or press the Down Arrow key to go back to hovering a child.

Now that you're hovering over the element you want to modify, you want to select it! To do so, you simply press 'S'. You should notice a smaller, darker outline appear around that element.
Now, when you move your mouse to hover over anything else, you will see that dark outline stay around the selected element, and the sidebar continues to display the information of that selected element.
This allows you to click on the various boxes and buttons, to modify the tag name, attributes and styles (explained later) of the element.

Try it on this element! Hover it, press 'S' to select it, then click on '<div>' in the left sidebar and replace it to say '<p>', and finally press Enter to confirm the change :)

You can also select multiple elements at a time. While having an element selected, just hover over another element and select it by pressing 'S' again. The sidebar will only ever display information common to all the elements you have selected. Any modifications you make through the sidebar will also be propagated to all selected elements.

To de-select an element, again just press 'S' while hovering over it. Or, press Escape. 
Pressing Escape generally gets you out of whatever you're doing; if you press Escape enough times you should always get back to the default state; with the default sidebar and nothing selected. 

Adding Elements

NOTE: This is currently a bit clumsy and subject to change.

There are a couple of different ways of creating new elements using the editor.

  1. Make sure no element is currently selected, then press 'A'. This will add many grey bars to the document, called "potential locations". The potential location nearest your cursor will be highlighted blue and left-clicking will insert a new element at that potential location.
    It can be hard to know at first what exact position in the document a potential location is referring to; there are often may spaced close together, seemingly all referring to the same position! However, they do differ.
    For example, the space between two sibling elements will have three potential locations. The first, will add the element as the last child of the top sibling. The second (middle) potential location, will add the element as another sibling to the two siblings. The third, will add the element as the first child of the bottom sibling.
    Observe! The three potential locations that are created between this element...
    ...and this element! We are direct siblings, as described in the example above. Experiment with adding nodes between and around us, seeing where they end up! Undo at any time using Ctrl+Z.
  2. Make sure no element is currently selected, highlight some text[2] in the document and press 'A'. This will wrap that text in a new element, and automatically select that newly created element. This is useful for adding extra styles to portions of text, for example adding emphasis to certain words or emboldening others, or whatever you want.
  3. Select an element, and press 'A'. This will wrap that element in a new element, and automatically select the newly created element. You can also select multiple elements and wrap a new element around all of them, though this requires all your selected elements to be direct siblings of each other (i.e. that they all share the same parent, and are all 'next' to each other).

Moving Elements

Currently, there is one way of moving existing elements, and that is simply selecting the element you wish to move, and then clicking and dragging it (in the same way you'd normally highlight text). 
When you start dragging, all of the potential locations will appear, and when you let go of the element it will be dropped into the location that was highlighted blue before the drag ended (if nothing was highlighted blue then nothing happens and the elements stays in its original location).

You can select multiple elements and move them all at once as well. Though note that, like with wrapping elements in new elements, this only works when the elements you've selected are direct siblings of each other (I call this forming a single 'island' of elements).

Removing Elements

To delete elements, press the 'Del' key, either when selecting elements or hovering over them.

If you want to delete an element without deleting its children, press 'U' instead. This key is meant to stand for 'unwrap', as that's really what you're doing; unwrapping the children.

Editing Text Content

To edit text, simply hover over the text you want to modify (or the element you want to add text content to) and press 'T'.
You should then find yourself able to modify, add and remove text in that element freely. 
When you're done, click somewhere (that isn't the element), or press 'Escape'.

One tip: You can press 'Enter' to create new lines of text like you would expect, however, it is often better to press 'Shift+Enter' instead. This is just a quirk of browsers' behaviour around contenteditable elements, that they'll arbitrarily wrap your content in extra <div> elements if pressing 'Enter' without also pressing 'Shift' (actually, this doesn't matter for inline containers like 'p' elements, but this explanation is already convoluted enough).
